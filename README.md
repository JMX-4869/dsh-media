# DSH 音视频插件 · dsh-av

**一个插件。两件事，其实是同一件事的两头。**

| 层 | 干什么 | 怎么实现的 |
| --- | --- | --- |
| **声音** | 把一段音频的音色换成某个人的 | hubert（波形→内容特征）+ rmvpe（音高）+ net_g（合成波形），**三个 ONNX 网络在 Node 里直接跑** —— 不依赖 Python，不依赖 torch |
| **视频** | 把音频渲染成片子 | 频谱 / 波形 / 歌词 / 曲线，拼 mp4 那一步要 ffmpeg |
| **音乐台** | 从零写一段曲子 | 内置的网页作曲台，装在设置页里；单文件、零依赖、全中文 |

**它们是一条链路，不是一个套件：**

```
音乐台写曲子 ──导出 WAV──▶ av { action:"convert" } 换音色 ──▶ av { action:"video" } 渲染成片
```

所以音乐台就在这个包里，不是另一个插件 —— 它是这条链路的**输入端**。

---

## 包

- 压缩包：`packages/dsh-av-0.5.0.zip`（**106 KB**，16 个文件）
- 源码：`src/dsh-av/`

目录里必须有：`index.js`（宿主：av 工具 + `/dsh-music` 路由）、`client.js`（客户端：设置页里的音乐台）、`www/音乐台.html`（页面本体）。

## 安装

1. 解压 `packages/dsh-av-0.5.0.zip` 到任意目录，例如 `<某处>/dsh-av`
2. 装那个**目录**（不是 zip）：

```
plugin_manager { action: "install_bundle", target: "<绝对路径>/dsh-av" }
```

3. **重启 DSH**（宿主半边要重新装载才会注册 `/dsh-music` 这条路由）
4. 音乐台在：设置 → 音乐台

## 模型

`models/` 约 **700 MB**，不在包里。先看缺哪几件：

```
av { action: "setup" }
```

它会打印缺的是哪一组、各自该多大、从哪来。没有模型时，除音色转换外的路径照常能跑。

## 音乐台能干什么

- **钢琴卷帘**：横向时间、纵向音高；点一下放音符，拖右边缘改长度，拖身体挪位置
- **步进网格**：一格一个十六分音符，一条轨一行
- **音色** 30 种（键盘 / 弦乐 / 管乐 / 电声 / 打击 / 氛围）+ 你自己录的采样
- **导出** WAV（手写 WAV 头、分段渲染）/ MIDI / 工程 JSON / 采样包
- **撤销** Ctrl+Z，**全屏** 一键铺满，**缩放** 4–64px 每格，**滚轮** 上下翻音高

## 已知限制

- `models/`（约 700 MB）不在包里
- 音乐台在 >2× 缩放时画布文字会略微软化
- 音乐台的音量 / 声像 / 音色改动不进撤销栈（滑杆拖动太频繁）
