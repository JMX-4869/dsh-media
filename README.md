# DSH 音视频插件

DeepSeek Harness 的**音视频**插件套件。

- **`dsh-av` 是本体** —— 音色转换、音频渲染成片
- **音乐台是配套的作曲台** —— 它导出的 WAV 正好可以喂给 dsh-av 做音色转换 / 渲染

| 包 | 版本 | 体积 | 说明 |
| --- | --- | --- | --- |
| **dsh-av** | 0.4.5 | 65.2 KB | 音视频插件本体：音色转换（纯 JS ONNX，不用 Python / torch）、音频渲染成片、ASR 兼容音频整理 |
| **音乐台** `@local/music-tab` | 1.0.1 | 43.5 KB | 配套作曲台，装在设置页：钢琴卷帘 + 步进网格 + 30 种音色 + 导出 WAV / MIDI / 工程 |

压缩包在 `packages/`，源码在 `src/`。

## 一条完整的链路

```
音乐台写曲子  ──导出 WAV──▶  dsh-av 换音色  ──▶  渲染成片（mp4）
```

## 安装

1. 解压：
   - `packages/dsh-av-0.4.5.zip` → `<某处>/dsh-av`
   - `packages/dsh-music-1.0.1.zip` → `<某处>/dsh-music`
2. 在 DSH 里装那个**目录**（不是 zip）：

```
plugin_manager { action: "install_bundle", target: "<绝对路径>/dsh-av" }
plugin_manager { action: "install_bundle", target: "<绝对路径>/dsh-music" }
```

3. 刷新页面。音乐台在：设置 → 音乐台。

### dsh-av 的模型

`models/` 约 **700 MB**，不在包里。没有模型时只能跑不依赖模型的那条路径（`av` 工具的 `setup` 会打印缺哪几件、各自该多大、从哪来）：

```
av { action: "setup" }
```

## 音乐台

单文件 `www/音乐台.html`（约 97 KB，零依赖、全中文），插件只做一件事：把这一页原样送出去。

- **钢琴卷帘**：横向时间、纵向音高；点一下放音符，拖右边缘改长度，拖身体挪位置
- **步进网格**：一格一个十六分音符，一条轨一行
- **音色** 30 种（键盘 / 弦乐 / 管乐 / 电声 / 打击 / 氛围）+ 你自己录的采样
- **导出** WAV（手写 WAV 头、分段渲染）/ MIDI / 工程 JSON / 采样包
- **撤销** Ctrl+Z，**全屏** 一键铺满，**缩放** 4–64px 每格，**滚轮** 上下翻音高

---

## 已知限制

- dsh-av 的 `models/`（约 700 MB）不在包里
- 音乐台在 >2× 缩放时画布文字会略微软化
- 音乐台的音量 / 声像 / 音色改动**不进撤销栈**（滑杆拖动太频繁）

---

## 许可

自用插件，未选许可证。第三方依赖（dsh-av 的 onnxruntime 等）各自遵循其原始许可。
